Quick Answer: How to Password Protect Folder Mac

Does macOS have a built-in "Right-click > Password Protect" feature? No. To lock a folder natively, you must use Disk Utility to convert the folder into a secure, encrypted disk image (.dmg). When you try to open this disk image, macOS will prompt you for the password before revealing the folder's contents.

What You Need Before Starting

Before you begin trying to password protect a folder on MacBook Pro, MacBook Air, or iMac, it's important to understand the landscape of macOS security.

If you search for "password protect folder macos sonoma" or "password protect folder mac ventura," you will find that Apple's core architecture hasn't changed regarding individual folder locks. macOS relies heavily on FileVault (which encrypts your entire drive) rather than item-level folder locking. Therefore, locking a specific folder requires creating an encrypted container.

macOS Version Compatibility

The native Disk Utility method outlined below works exactly the same across macOS Catalina, Big Sur, Monterey, Ventura, Sonoma, and Sequoia. No third-party software is strictly required for local, Mac-only protection.

How to Password Protect a Folder on Mac — 4 Methods

We've tested the most common approaches to folder security. Here is exactly how to execute each one, complete with limitations and difficulty ratings.

Disk Utility Folder Lock: Step-by-Step Guide for Mac Medium

This is the official, built-in way to secure a folder on Mac without downloading extra software. It creates a `.dmg` file that acts like a virtual secure USB drive.

  1. Open Disk Utility (found in Applications > Utilities, or via Spotlight Search).
  2. In the top menu bar, click File > New Image > Image from Folder...
  3. Select the folder you want to password protect and click Choose.
  4. In the "Encryption" dropdown menu, select 128-bit AES encryption (recommended for speed) or 256-bit AES encryption (maximum security).
  5. Enter and verify your desired password. Do not check "Remember password in my keychain" if others use your Mac account.
  6. In the "Image Format" dropdown, choose read/write so you can add or remove files later. Click Save.

How to verify it worked: Delete the original, unencrypted folder (empty the trash). Double-click the new `.dmg` file. You should immediately be prompted for your password.

Limitation: Cross-Platform Friction

If you put this encrypted `.dmg` file on an external hard drive or flash drive and plug it into a Windows PC, Windows will not be able to open it natively.

Password Protect Folder Mac Terminal (Advanced) Hard

If you prefer command-line interfaces or want to password protect multiple files at once using scripts, you can create an encrypted zip via Terminal.

  1. Open Terminal.
  2. Type cd followed by a space, then drag the folder containing your files into the Terminal window to set the directory. Press Return.
  3. Type the command: zip -er ArchiveName.zip folder_to_protect/
  4. Terminal will prompt you to enter a password and verify it (the characters won't show as you type).

Best for: Developers or users comfortable with CLI who need to quickly secure documents before emailing.

Using 7-Zip / Keka for ZIP Password Protection Easy

While people often search for "7 zip how to password protect" on Mac, 7-Zip is natively a Windows app. However, Mac users can use free alternatives like Keka to achieve the same 7-Zip AES-256 encryption password protect archive.

This method restricts document access by compressing it into an encrypted bundle. Like the Terminal method, you must unpack the file to edit it, then re-pack it to secure it again.

Why Document Password Protection Is Not the Same as Encryption

If you rely solely on application-level passwords (like trying to restrict document access in Word or Excel), you might be leaving data vulnerable. Dedicated folder protection software goes significantly deeper, offering layers of security that standard permissions cannot match.

An open password mathematically encrypts the file; a permissions password merely asks the software to politely prevent document copying or editing. Dedicated folder lockers enforce encryption at the OS level, bypassing weak application permissions entirely.

One of the biggest security risks is emailing a password to a colleague so they can unlock a file. Advanced tools utilize asymmetric encryption, allowing you to share an encrypted file safely. If the recipient is authorized, they access the file using their own unique credentials, meaning your master password never has to leave your head.

Modern protection isn't just about locking folders. Premium macOS tools include dedicated vaults for your raw text. Instead of keeping credit card numbers or sensitive project ideas in a vulnerable text file, you can store them in dedicated, encrypted "Secret Notes" or "Wallets" that lock instantly.

Can I create a password protected folder in Google Drive? Natively, no. Google Sheets might say "couldn't be opened for import. if the file is password protected, try removing the password." Using local software allows you to encrypt the files before they sync to the cloud, ensuring Dropbox or Google (and anyone with your link) cannot read the contents.

What to Do If You Forget a Document Password

High-security encryption is unforgiving by design. If you've locked a folder and cannot access it, here are the owner-safe recovery steps.

No Backdoors in AES-256

True encryption (like Disk Utility or Folder Lock) does not have a "forgot password" button. If the password is lost, the data is mathematically unrecoverable. Do not trust third-party tools claiming to easily "crack" Mac folder passwords.

Remove Password from a Protected Folder on Mac

If you remember the password but simply want to remove the protection:

  1. Open the encrypted `.dmg` file and enter your password.
  2. Copy all files out of the secure container and paste them into a normal, unencrypted Mac folder.
  3. Eject the encrypted drive.
  4. Delete the `.dmg` file. Your files are now permanently unprotected in the new folder.

Troubleshooting Shared Cloud Files

If a colleague says a file "couldn't be opened for import" in Google Docs, it means you applied a password to the Office/PDF file before uploading. You must remove the document-level password locally, re-upload it, and use Google's sharing permissions to restrict access instead.

Frequently Asked Questions

  • Does Mac have a built-in folder password feature?
    macOS does not have a simple "right-click to lock" feature for folders. Instead, you must use the built-in Disk Utility app to convert the folder into an encrypted disk image.
  • How to password protect a folder on Mac for free?
    Use Disk Utility. Open Disk Utility > File > New Image > Image from Folder. Choose your folder, select 256-bit AES encryption, set your password, and save.
  • Can I password protect a folder in Finder on Mac?
    Not directly. Finder relies on account-level permissions (FileVault). To lock a specific folder so other logged-in users can't see it without a password, you must use Disk Utility or third-party encryption software.
  • Is FileVault the same as folder password protection on Mac?
    No. FileVault encrypts your entire Mac hard drive while it is turned off. Once you log into your Mac user account, all your folders are decrypted and visible. Folder-level protection keeps specific items locked even while you are actively using the Mac.
  • Can I make a Google Doc password protected?
    Google Docs does not offer built-in password protection. To secure a document in Google Drive, you must encrypt it on your Mac first (using Disk Utility or third-party software), then upload the encrypted file.
